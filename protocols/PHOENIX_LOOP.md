# Phoenix Loop

INPUT → MEMORY → REASON → EXECUTE → VERIFY → REFLECT → RECORD → EVOLVE

1. Capture intent.
2. Load relevant state.
3. Construct an explicit plan.
4. Execute only authorized actions.
5. Capture evidence.
6. Verify the observed result.
7. Preserve success or failure in the append-only ledger.
8. Feed verified lessons back into memory.

Invariant: never promote an unverified result.
