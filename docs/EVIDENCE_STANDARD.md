# Evidence Standard

ZAAI-SYSTEM is an experimental notebook/package repository. Documentation, notebook cells, and architectural descriptions do not by themselves establish production readiness or independent verification.

## Status levels
- Implemented — code/notebook logic exists.
- Tested — a current reproducible execution is recorded.
- Benchmarked — inputs, methodology, and artifacts are available.
- Verified — independent reproduction/review is linked.
- Designed — planned/specification material.
- Historical — preserved provenance, not current capability.

## Release rule
Before claiming a capability is production-ready, record the exact commit, environment, dependency versions, execution command, outputs, failures/limitations, and security/privacy review where applicable.

Notebook demonstrations should identify external services, credentials, data handling, and any assumptions required for reproduction.
