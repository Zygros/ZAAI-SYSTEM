# Repository Quality Standard

This repository uses explicit evidence boundaries and separates runnable implementation from architecture, historical material, and unverified claims.

## Status vocabulary
- **Implemented** — runnable and documented.
- **Prototype** — partial, local, stubbed, or not production-hardened.
- **Designed** — specified but not sufficiently implemented.
- **Historical** — preserved source material.
- **Verified** — independently inspectable evidence exists.
- **Unverified** — retained pending evidence.

## Quality gate
Production, security, benchmark, independence, and performance claims must link to reproducible artifacts or independent evidence. Never commit secrets or credentials. Identify upstream material and preserve provenance.
